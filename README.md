### What I've Built

- 🎥 **FlowShare** — WebRTC peer-to-peer video and file sharing. Django Channels signalling, under **300 ms** connection setup across 2–5 concurrent peers, chunked transfers up to **50 MB**, deployed on AWS EC2/S3 behind Nginx.
  <br/>`Django` `WebRTC` `PostgreSQL` `Nginx` `AWS`
- 🌾 **AgriRent** — farmer and equipment-owner marketplace with a Flask RAG semantic search engine (**~35% better relevance** than keyword search across 50 test queries) and a conflict-aware booking API.
  <br/>`React` `Node.js` `Express` `MongoDB` `Flask` `ChromaDB`
- 📺 **YTubeMind** — chat with any YouTube video using retrieval-augmented question answering over its transcript.
  <br/>`LangChain` `FAISS` `Google Gemini`
- 📱 **Scrollpedia** — scrollable Wikipedia learning feed; Python scraper indexed **1,000+ articles** into Supabase, with like and tag-filter APIs.
  <br/>`React Native` `Hono.js` `Supabase` `Python`
